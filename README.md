# MLMVPN Fast Pool — public distribution

This repository contains selected **public-source proxy configurations** and signed catalog artifacts only. No MLMVPN private source code, signing secrets or user feedback is stored here.

Clients verify the Ed25519 signature and SHA-256 shard digest using the public key pinned in the desktop application. An HTTP 200 response alone is not sufficient.

Source availability, central test results and country labels do not guarantee availability on any particular Iranian network. Each connection is tested locally. Public configs may be operated by third parties; do not assume they are trusted operators.

Sources: [0xRadikal/Free-v2ray-Configs](https://github.com/0xRadikal/Free-v2ray-Configs), [iampedii/whitedns-sub](https://github.com/iampedii/whitedns-sub). Upstream ownership and applicable terms remain with their authors.

Distribution through GitHub raw and a tested jsDelivr delivery path provides multiple delivery networks. jsDelivr's GitHub integration still depends on GitHub for uncached origin content. Previously verified local snapshots and the bundled bootstrap remain available offline.
